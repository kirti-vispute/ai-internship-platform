# Scraped Engineering Internships & Jobs — Review File

**Purpose:** Raw, unedited listings gathered by browsing public search/listing pages on Internshala, Unstop, and Wellfound (AngelList Talent), for the InternAI team to review before anything is imported into the live database. Nothing in this file has been imported anywhere — it is source material only.

**Gathered on:** 2026-08-27 (initial 22 listings); topped up to 25 on 2026-08-28 (3 additional listings — 1 Internshala, 1 Unstop, 1 Wellfound)

**Scope:** Engineering-background roles only (Software Engineering, CS, IT, Web Dev, Data Engineering/Science, AI/ML, Embedded/Robotics, VLSI/Electronics, etc.). Non-engineering roles (marketing, sales, HR, finance) that appeared in search results were skipped.

**Total listings:** 25 (9 Internshala, 7 Unstop, 9 Wellfound).

**LinkedIn exclusion:** LinkedIn was deliberately NOT browsed or scraped for this file. LinkedIn's Terms of Service explicitly prohibit automated data collection from the site, and they actively enforce this (IP/account blocking, legal action). If the team wants LinkedIn listings, use LinkedIn's official Jobs API / Talent Solutions partner program instead of scraping.

**How to read each entry:** Fields are as shown publicly on the listing page at the time of gathering. The "Description" block is copied verbatim from the page (not summarized/paraphrased) so the team can review the actual source wording. Always re-check the source URL before importing — postings can be edited, filled, or removed at any time.
