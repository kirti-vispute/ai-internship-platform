# InternAI Brand System

Unified branding for the InternAI internship and placement platform. All assets use the existing palette (`#1f6fff`, `#22d3ee`, `#0f172a`) without theme changes.

## Logo System

| Asset | Path | Usage |
|-------|------|--------|
| Primary Logo | `frontend/public/brand/logo-main.svg` | Marketing, hero |
| Compact Logo | `frontend/public/brand/logo-compact.svg` | Dense UI |
| Icon Only | `frontend/public/brand/logo-icon.svg` | Empty states, sidebars |
| Navbar Logo | `InternAILogo` variant `navbar` | Top navigation |
| Footer Logo | `frontend/public/brand/logo-footer.svg` | Site footer |
| Watermark | `frontend/public/brand/logo-watermark.svg` | PDF background |
| Loading Logo | `frontend/public/brand/logo-loading.svg` | Loaders |

React component: `frontend/components/brand/internai-logo.tsx`

## Favicon System

- Source: `frontend/app/icon.svg`
- Generated PNGs: run `npm run brand:favicons` in `frontend` (requires `sharp`)
- Outputs: `favicon-16.png`, `favicon-32.png`, `favicon-48.png`, `apple-touch-icon.png` (180), `favicon-512.png`, `public/favicon.ico`

## Taglines

- Primary: **AI-Powered Internship & Placement Management**
- Alternate: **Connecting Talent with Opportunity**

Defined in `frontend/lib/brand.ts`.

| Component | Path |

## Email Branding

HTML wrapper: `backend/src/services/email-template.service.js`  
Applied automatically in `notification-queue.service.js` for OTP, applications, interviews, and status emails.

## PDF Branding

Enterprise reports use InternAI header, metadata, verification badge, watermark (`InternAI Verified · Generated by InternAI`), and footer via `backend/src/services/report-pdf.service.js`.

## Integration Map

- **Navbar / Footer / Auth / Landing** — logo + tagline
- **Dashboard shells** — `PortalBrandHeader` (intern, company, admin)
- **Page headers** — `DashboardPageHeader` includes InternAI eyebrow
- **Empty states** — branded presets in `BRANDED_EMPTY_STATES`
- **Emails** — branded HTML template
- **PDFs** — watermark + corporate layout

## Motion Guidelines

- Subtle Framer Motion on logo (landing, auth)
- No heavy Three.js scenes in product flows
- Loader uses gentle pulse and floating animation only
